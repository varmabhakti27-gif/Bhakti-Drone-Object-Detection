# AI-Based Drone Object Detection Using YOLO26n

##  Project Overview

This project focuses on detecting and identifying objects in drone-view images using the YOLO26n object detection model.

The model is fine-tuned on the VisDrone2019-DET dataset to detect objects such as pedestrians, people, bicycles, cars, vans, trucks, buses, and motorcycles.

##  Dataset

- **Dataset:** VisDrone2019-DET
- **Source:** VisDrone Dataset
- **Task:** Object Detection
- **Number of Classes:** 10

##  Model and Technologies

- YOLO26n
- Python
- Ultralytics
- Google Colab
- PyTorch

##  Model Evaluation

The selected model was evaluated at an image size of 1536.

|   | Metric    | Result |
| - | --------- | -----: |
|   | Precision | 52.89% |
|   | Recall    | 45.76% |
|   | mAP50     | 45.84% |
|   | mAP50-95  | 27.06% |

##  Detection Settings

- Image Size: 1536
- Confidence Threshold: 0.25
- Bounding Boxes: Enabled
- Class Labels: Enabled
- Confidence Scores: Enabled

## How to Run

### 1. Install Required Libraries

Make sure Python is installed, then install Ultralytics:

```bash
pip install ultralytics
```

### 2. Download the Trained Model

Download the trained YOLO26n model:

[Download best_model.pt](https://drive.google.com/file/d/1Z2R6fs4aZp0hfVnNBoYF8xRwiVUZkxCH/view?usp=sharing)

Place the downloaded `best_model.pt` file in the `task1_ai_ml` folder.

### 3. Run Object Detection

Open a terminal in the `task1_ai_ml` folder and run:

```bash
python src/detect.py --model best_model.pt --source path/to/image.jpg
```

Replace `path/to/image.jpg` with the path of your input image.

### 4. View the Results

The detection results will be saved in the output folder generated by the script.

You can view the output images with detected objects, bounding boxes, class labels, and confidence scores.
